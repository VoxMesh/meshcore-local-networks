# MeshCore — справочник локальных сетей

Радиопрофили MeshCore по городам и территориям. Если в одной местности работают несколько сетей, их профили приведены отдельно.

- [Каталог JSON](catalog.json)
- [Схема данных](schema.json)

## Формат

`locations` — список городов и территорий. `id` используется для идентификации территории; `networks` содержит отдельные профили с постоянными ID. Профили отображаются в порядке их записи. `parent_id` связывает территорию с более общей, например Зеленоград — с Москвой и областью.

В объекте `radio`:

| Поле | Значение |
| --- | --- |
| `frequency_hz` | Частота, Гц |
| `bandwidth_hz` | Полоса, Гц |
| `sf` | Spreading Factor |
| `cr` | Знаменатель Coding Rate: `6` — `4/6`, `8` — `4/8` |

`band` обозначает диапазон: `"868"` или `"433"`. `lat` и `lon` — координаты для поиска ближайших населённых пунктов. `updated` — дата изменения записи в каталоге, `schema_version` — версия его структуры. Необязательные `channels` и `source` добавляются, когда известны конкретные публичные каналы и страницы местных сообществ.

## Исправления и дополнения

Настройки лучше уточнять у администраторов местных сетей. Если найдена ошибка или отсутствует сеть, можно [предложить исправление в Issues](https://github.com/VoxMesh/meshcore-local-networks/issues).

Укажите город, сеть и актуальные частоту, BW, SF и CR. По возможности приложите ссылку на опубликованные настройки или сообщение администрации местного сообщества.
