# MeshCore — справочник локальных сетей

Радиопрофили MeshCore по городам и территориям. Если в одной местности работают несколько сетей, их профили приведены отдельно.

- [Каталог JSON](catalog.json)
- [Схема данных](schema.json)
- [Скачать JSON](https://raw.githubusercontent.com/VoxMesh/meshcore-local-networks/main/catalog.json)

## Формат

`locations` содержит города и территории, `networks` — их радиопрофили. У каждой территории и профиля свой постоянный `id`. Профили приведены в порядке записи. `parent_id` связывает территории, например Зеленоград с Москвой и областью.

В объекте `radio`:

| Поле | Значение |
| --- | --- |
| `frequency_hz` | Частота, Гц |
| `bandwidth_hz` | Полоса, Гц |
| `sf` | Spreading Factor |
| `cr` | Знаменатель Coding Rate: `6` — `4/6`, `8` — `4/8` |

`band` — диапазон `"868"` или `"433"`. `lat` и `lon` — справочная точка для поиска ближайших населённых пунктов. `updated` — дата изменения записи, `schema_version` — версия формата.

Необязательные поля: `community_url` — ссылка на местное сообщество, `channels` — публичные радиоканалы вида `#имя`, `source` — ссылка на опубликованные параметры профиля.

## Нашли ошибку или хотите добавить город или сеть?

Если вашего населённого пункта или местной сети нет в справочнике либо настройки указаны неверно, [**предложите исправление или дополнение на GitHub**](https://github.com/VoxMesh/meshcore-local-networks/issues/new).

Укажите населённый пункт, название сети и известные радиопараметры (частоту, BW, SF, CR). По возможности приложите ссылку на актуальные настройки или подтверждение от администрации местной сети.

Редактировать JSON самостоятельно не нужно.

Если у вас нет аккаунта GitHub или возникли трудности с обращением, можно написать в [Telegram](https://t.me/MeshCore_Community_RU/24), [Discord](https://discord.gg/GVVPBXhBeF) или [Matrix](https://matrix.to/#/%23meshcore-community-ru:matrix.org).
