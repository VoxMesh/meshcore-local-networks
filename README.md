# MeshCore — справочник локальных сетей

Радиопрофили локальных сетей MeshCore по городам и территориям. В одной местности может быть несколько профилей — они приведены отдельно.

- [Каталог JSON](catalog.json)
- [Схема данных](schema.json)

## Формат

`locations` — список населённых пунктов и территорий. Их `id` соответствуют кодам Regions & Scopes. У каждой территории есть массив `networks` с отдельными постоянными ID радиопрофилей.

Параметры в объекте `radio`:

| Поле | Значение |
| --- | --- |
| `frequency_hz` | Частота в герцах |
| `bandwidth_hz` | Полоса в герцах |
| `sf` | Spreading Factor |
| `cr` | Знаменатель Coding Rate: `6` означает `4/6`, `8` означает `4/8` |

`lat` и `lon` — координаты для поиска ближайших городов. `parent_id` связывает вложенную территорию с более общей: для Зеленограда это `mow` (Москва и Московская область). Приложение может показывать профили обеих территорий.

`updated` — дата изменения записи в каталоге. `schema_version` — версия структуры данных.

## Исправления и дополнения

Актуальные настройки лучше уточнять у администраторов местных сообществ. Ошибку или новую сеть можно [предложить в Issues](https://github.com/VoxMesh/meshcore-local-networks/issues).

Укажите населённый пункт, название сети, частоту, BW, SF и CR. По возможности приложите ссылку на опубликованные настройки или подтверждение администратора местной сети.
